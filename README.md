# Генератор статей для Яндекс.Дзен — intrelocations.ru

Интерактивный инструмент для написания рекламных статей по фреймворку **БАРСУК** (6 шагов).

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env
# Вставьте ваш ANTHROPIC_API_KEY в .env
python app.py
```

Открыть: http://localhost:5000

## Использование

1. Введите тему статьи
2. Нажмите «Написать статью»
3. Дождитесь завершения всех 6 шагов
4. Скопируйте готовый текст кнопкой «Готово для Дзена»
